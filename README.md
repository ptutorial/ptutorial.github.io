# ptutorial.github.io — Engineering Portfolio

Premium single-page personal portfolio for an engineer building scalable systems, intelligent automation, AI applications, APIs, data platforms, and cloud infrastructure.

## Stack

- Semantic HTML5
- CSS3 with responsive layout and design tokens
- Vanilla JavaScript for navigation, scroll progress, reveal animations, and counters
- No framework or build step required

## Personalization

The content is intentionally structured so it can be edited directly in `index.html`. Replace the role history, project metrics, education/certifications, LinkedIn URL, and any placeholder company names before publishing publicly.

## Local preview

Serve the directory with any static web server, for example:

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`.

## GitHub Pages

The repository is `ptutorial/ptutorial.github.io` and is configured around GitHub Pages conventions. The site is a single-page experience with hash navigation and requires no build command.
